Documented in `RECOVERY.md` so the reasoning isn't lost.

**Priority:** Medium — confirmed as a real, live gap during tonight's own manual testing of B-044: `"Test/query"` against a `rest_api` tool's flat `base_url` 404'd, because every action for a tool POSTed to the identical URL regardless of action name. Real REST APIs have more than one endpoint.

**Resolution (2026-08-06):** New `gateway_tools.action_paths JSONB` column (migration `010`, `{"<action>": {"path": "...", "method": "..."}}`) — JSONB over a new table, matching this schema's existing convention for small structured per-row config (`alert_rules.condition_config`, `notification_config.config`, `episodes.steps`) and avoiding a join on every dispatch. `toolrouter.Forward`: when the resolved row has `ActionPaths` entries and the incoming action matches one, dispatches to `joinURLPath(base_url, entry.Path)` with `entry.Method` (default `POST`) instead of the flat `base_url` POST.
